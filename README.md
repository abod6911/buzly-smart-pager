# 🔔 Buzly - Smart Restaurant Order Pager & Queue Web App
### نظام بيجر واستدعاء الزبائن الذكي للمطاعم والكافيهات

> بديل تجاري رقمي فاخر لأجهزة البيجر البلاستيكية المكلفة والقابلة للضياع والأعطال. يعمل مباشرة عبر متصفح جوال الزبون وبدون الحاجة لتحميل أي تطبيق!

---

## ✨ المميزات الرئيسية (Core Features)

1. **شاشة الكاشير السريعة (`/staff`)**:
   - لوحة إدخال رقمية (Numpad) فائقة السرعة مع دعم لوحة المفاتيح الفعلية لإضافة أي طلب في أقل من ثانيتين.
   - أزرار الوقت المتوقع للتحضير السريعة (5 د، 10 د، 15 د، 20 د، 30 د).
   - تقسيم تفاعلي للطابور: **قيد التحضير (Preparing)** و **جاهز للاستلام (Ready)**.
   - زر نداء فوري **"🔔 نداء العميل - جاهز"** يطلق جرس واهتزاز جوال الزبون لحظياً.
   - زر **"🔄 إعادة تنبيه (Re-ping)"** مع عداد للتنبيهات المتكررة.
   - زر **"✅ تم التسليم (Completed)"** لإنهاء الطلب وأرشفته.
   - مودال توليد وطباعة **كود QR ديناميكي** للطلب أو للكاونتر كاملاً.

2. **شاشة العميل والبيجر الذكي (`/track` & `/track/[orderNumber]`)**:
   - شاشة إدخال رقم الطلب عند مسح الكود العام.
   - بانر تفعيل التنبيه الذكي:
     - يطلب صلاحية إشعارات النظام `Notification.requestPermission()`.
     - يفعل بقاء الشاشة نشطة ومنع القفل `navigator.wakeLock.request('screen')`.
     - يفك حظر الصوت في متصفحات الجوال (Web Audio Context Unlock).
     - نصائح وتوجيهات لمستخدمي الآيفون (iOS) للإشعارات مع الشاشة المغلقة.
   - **حالة التحضير (Preparing)**: حلقة رادار نابضة مع عداد تنازلي للوقت المتبقي وعبارات طمأنة عربية راقية.
   - **حالة الجاهزية (Ready Alert)**: تحول فوري للشاشة إلى الأخضر الزمردي عالي التباين، رنين جرس فندقي مستمر عبر **Web Audio API** بدون أي ملفات خارجية، اهتزاز متزامن للجوال، إطلاق قصاصات الاحتفال (Confetti)، وإشعار نظام منبثق.
   - زر **"استلمت طلبي"** لإسكات الصوت وتأكيد الاستلام.

3. **المزامنة الفورية المزدوجة (Dual-Engine Realtime)**:
   - **محلياً وتجريبياً فوراً:** عبر `BroadcastChannel` + أحداث `localStorage` لمزامنة فورية بلغت زمن انتقال 0 ملي ثانية بين التبويبات بدون أي مفاتيح API.
   - **جاهز للإنتاج مع Supabase:** ملف `supabase_schema.sql` جاهز للتنفيذ مع تفعيل `supabase_realtime` وسياسات الأمان RLS.

## 🚀 التشغيل السريع (Quick Start)

### 1. تثبيت الحزم وتشغيل الخادم المحلي:
```bash
npm install
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2. تجربة المزامنة الفورية خلال 10 ثوانٍ:
1. افتح **التبويب الأول**: `http://localhost:3000/staff` (شاشة الكاشير).
2. افتح **التبويب الثاني**: `http://localhost:3000/track/104` (شاشة العميل للطلب #104).
3. في شاشة العميل، اضغط على زر **"تفعيل جرس التنبيه والشاشة"**.
4. في شاشة الكاشير، اضغط على زر **"🔔 نداء العميل - جاهز الآن"** للطلب #104.
5. شاهد شاشة العميل تتحول فوراً إلى الأخضر الزمردي ويبدأ جرس الرنين الفندقي والاهتزاز!

## 🗄️ ربط قاعدة بيانات Supabase (اختياري للإنتاج)

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح الـ **SQL Editor** في Supabase وانسخ محتوى ملف `supabase_schema.sql` واضغط **Run**.
3. أنشئ ملف `.env.local` في مجلد المشروع وضع فيه:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
4. أعد تشغيل التطبيق وستتم المزامنة تلقائياً عبر سحابة Supabase Realtime!

- **حالة الجاهزية والنداء:** زمردي فوسفوري مشع Emerald (`#10B981`).
- **حالة التحضير والانتظار:** كهرماني دافئ Amber (`#F59E0B`).
- **الخطوط:** خط Cairo العربي الأصيل مع دعم كامل للاتجاه من اليمين لليسار (RTL).
